test1 — клиентский мод для Minecraft Java 1.21.1 + Forge 52.1.14

- F8 открывает и закрывает меню.
- Зелёные AABB-контуры показывают других игроков, кроме наблюдателей.
- Красные AABB-контуры показывают лодки, вагонетки и подходящие по размеру не-живые сущности, включая потенциальные сущности техники из других модов.
- Кнопки меню включают и выключают каждый вид контуров; экран не ставит игру на паузу.
- Контуры рисуются сквозь блоки.

Сборка требует JDK 21 и Gradle 8.8. В IntelliJ выберите JDK 21 для Gradle и Gradle 8.8 как локальную установку, затем выполните Gradle Tasks > build > build.

Готовый JAR: build/libs/test1-1.0.0.jar
