test1 — исходный код для Minecraft Java 1.20.1 + Forge 47.x

В этом варианте контуры рисуются напрямую через BufferBuilder, с отключением depth test во время фактической отрисовки, чтобы быть видимыми сквозь блоки.
Меню открывается Page Up; переключатели игроков и техники сохранены.

Сборка: откройте папку проекта в IntelliJ IDEA и запустите Gradle Tasks > build > build.
Это исходный код; сборка в настоящем Minecraft/Forge здесь не проверена. Если появится ошибка, пришлите её текст.
